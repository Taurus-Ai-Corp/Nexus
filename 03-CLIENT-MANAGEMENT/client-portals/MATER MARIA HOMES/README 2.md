# Mater Maria Homes Project

## Overview
Mater Maria Homes is an AI-powered wellness community real estate project targeting NRI (Non-Resident Indian) investors in Kerala, India. The project combines luxury villa living with Ayurvedic wellness, smart home technology, and sustainable community design.

## Folder Structure
This workspace follows a strategic document organization pattern for clear separation of concerns:

- **`business-documents/`** - Legal contracts, invoices, agreements, and official paperwork
- **`devops/`** - Deployment scripts, domain handoff documentation, and infrastructure details  
- **`inputs/`** - Source data files, spreadsheets, and raw materials
- **`mater-maria/`** - Original project folder (legacy - see technical_design for current codebase)
- **`meta-ads-campaign/`** - Marketing assets, ad creatives, and campaign materials
- **`product_management/`** - Product requirements, feature specifications, and user stories
- **`quality_assurance/`** - Testing protocols, QA plans, and validation documentation
- **`strategic_documents/`** - High-level plans, market analysis, and executive summaries
- **`technical_design/`** - Technical architecture, source code, and implementation details

## Key Deliverables
- Next.js-based investor portal with multi-currency support (INR/USD)
- AI-powered ROI calculator for real estate investments
- WhatsApp integration for investor communication
- Comprehensive property gallery with 3D tours
- Smart estate management dashboard
- Domain transfer and DevOps handoff documentation

## Technology Stack
- Frontend: Next.js 14, React 19, TypeScript, Tailwind CSS
- Backend: Supabase (PostgreSQL, Auth, Storage)
- Payments: Razorpay integration
- Analytics: PostHog, Google Analytics
- Deployment: Vercel
- AI Integration: Gemini API for chatbot functionality

## Current Status
Production-ready investor portal deployed at mater-maria.vercel.app
