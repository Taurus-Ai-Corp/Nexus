# Inputs Folder

## Purpose
This folder contains raw input data, source files, spreadsheets, and other materials that serve as inputs to various processes in the Mater Maria Homes project.

## Contents
- **Spreadsheets** - Excel/Google Sheets files with data for analysis, tracking, or import
- **Raw Data Files** - CSV, JSON, XML, or other data formats for processing
- **Source Documents** - Original files received from clients, vendors, or partners
- **Reference Materials** - Documents used as references for creation of other content
- **Media Assets** - Original photos, videos, or audio files before processing/optimization
- **Design Source Files** - Photoshop, Illustrator, Sketch, or Figma files

## Key Files Found
- `mater-maria-edits.xlsx` - Spreadsheet containing edits, feedback, or data for the Mater Maria Homes project

## Substructure (if organized by type)
```
inputs/
```
