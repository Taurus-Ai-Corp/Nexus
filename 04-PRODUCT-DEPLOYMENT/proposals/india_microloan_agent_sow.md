# Pilot Engagement Agreement: India Micro-loan Repayment AI Agent

**Parties:**
- **Taurus AI** (operating as NeoVibe by Taurus AI, License #68122, IFZA Dubai)

**Effective Date:** [Date]
**Pilot Duration:** 4 weeks (covering one full repayment cycle for daily/weekly micro-loans)

## 1. SCOPE OF WORK
Taurus AI shall provide a complimentary AI-powered repayment optimization agent for [Client Name] including:
- Analysis of historical repayment patterns (anonymized) to identify cash-flow stress points
- Configuration of the Cash-Flow Agent to generate SMS/WhatsApp reminders and repayment suggestions
- Integration via API or file-based exchange (CSV) for borrower data and repayment status
- Dashboard showing predicted on-time payment rates and recommended intervention times
- Dynamic pricing experiments based on borrower segments to optimize interest rates and repayment terms
- Integration roadmap for AI MCP payoff tools to enable modular repayment prediction and negotiation capabilities
- Reliability metrics using state machine monitoring to ensure agent consistency and auditability
- One (1) virtual workshop to review agent performance and recommendations

## 2. CLIENT RESPONSIBILITIES
- Provide anonymized historical repayment data (last 3-6 months) for at least 50 active micro-loans
   - Required fields: loan ID, borrower segment (trader/hotelier/grocer), loan amount, frequency (daily/weekly), due dates, actual payment dates, amounts paid
- Designate a primary point of contact (preferably Head of Retail Lending or Collections)
- Allocate 1-2 hours of staff time for configuration workshop and weekly review
- Commit to testing the agent's recommendations on a subset of loans (at least 25 loans) for 2 weeks
- Provide feedback on recommendation usability and any observed impact on repayment behavior

## 3. DELIVERABLES
- **Anonymized Data Analysis Report** (PDF): Insights on repayment patterns, stress points, and segmentation
- **Configured Cash-Flow Agent** (Docker-compose deployment) with:
  - SMS/WhatsApp reminder templates (in English and local language if provided)
  - Repayment suggestion engine (based on borrower cash-flow patterns)
  - Simple web dashboard showing predictions and recommendations
- **Weekly Performance Report** (PDF): Predicted vs. actual on-time payment rates, recommended interventions
- **Executive Summary** (1-page): Key findings and recommended next steps for rollout
