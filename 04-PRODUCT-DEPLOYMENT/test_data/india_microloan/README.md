# India Micro-loan Repayment Agent - Test Data

This directory contains sample data for testing the India Micro-loan Repayment AI Agent MVP.

## Files

### sample_borrowers.csv
Sample borrower data representing Muthoot FinCorp's micro-business loan portfolio (traders, hoteliers, grocers).

### sample_repayments.csv
Sample repayment history showing patterns of timely, late, and missed payments.

### sample_loan_terms.csv
Sample loan terms including amounts, frequencies, and durations.

## Usage
1. Place these files in the input directory of the agent (or configure the agent to read from these paths)
2. The agent will analyze repayment patterns and generate SMS/WhatsApp reminders
3. Expected output: Recommendations for optimal reminder timing and repayment suggestions based on borrower cash-flow patterns

## Sample Data Structure
The CSV files contain anonymized data with the following fields:

### borrowers.csv
- borrower_id: Unique identifier
- segment: Business type (trader/hotelier/grocer)
- city_tier: Urban/rural classification
- avg_monthly_income: Estimated monthly revenue
- loan_count: Number of active loans
- preferred_contact: SMS/WhatsApp/Call

### loan_terms.csv
- loan_id: Unique loan identifier
- borrower_id: Associated borrower
- principal_amount: Loan amount in INR
- frequency: Repayment frequency (daily/weekly)
- installment_amount: Amount per installment
- total_installments: Total number of installments
- start_date: Loan start date
- end_date: Expected end date

### repayments.csv
- repayment_id: Unique identifier
- loan_id: Associated loan
- due_date: Expected repayment date
- actual_date: Actual repayment date (NULL if missed)
- amount_paid: Amount paid
- days_late: Days late (negative if early)
- status: Status (on_time/late/missed/early)
