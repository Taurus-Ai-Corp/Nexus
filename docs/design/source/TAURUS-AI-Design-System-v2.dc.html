SOURCE OF TRUTH
One tokens.json in the DTCG 2025.10 format — the first stable, vendor-neutral release, with native support for oklch and for theming via group inheritance rather than file duplication. Style Dictionary compiles it to CSS, TS, Swift and Kotlin.
BRAND × MODE COMPOSE
data-brand and data-mode are orthogonal attributes on <html>. Four brands × two modes = eight resolved themes from one component library. Dark is canonical; light exists for print, PDF exports and regulator portals only.
CI GATE
Every theme is a fresh contrast obligation. The build fails on any semantic text/surface pair below the target — WCAG 2.2 AA for the legal floor, APCA Lc tracked alongside it because WCAG 2.x overstates contrast near black and cannot be used to design dark mode.

Motion · Stepper-Quantized

The signature is machine motion: things arrive at discrete addresses rather than easing into place. Continuous easing is reserved for opacity and colour. Anything that represents a state in a verifiable pipeline moves in steps — the motion itself asserts that the system is deterministic.

MOTION BUDGET
Two animating elements per viewport, maximum. Heavy motion never sits on a critical path — a user completing a KYC upload sees no ambient animation at all.
REDUCED MOTION
Honoured per component, not once globally. Stepper transport becomes an instant state change; the emitter stops breathing; the WebGL viewport renders one static frame.
WHAT NEVER MOVES
Hashes, timestamps, consensus IDs and monetary values never animate in or count up. Evidence appears; it does not perform.

RECOMMENDATION
Ship C as the default and A only on the two pages that earn it — the Gridera hero and the enterprise proof page. Treat B as a design tool, not a runtime.
The raymarched shader is the honest fit for four sites and ten sub-products: it is procedural, so a new platform costs one uniform change rather than a modelling pass, and at roughly 80 KB it will not push a compliance console past its performance budget. Reach for R3F only where a video texture must genuinely live on a mesh face; that capability is the sole reason A exists, and it should not be paid for on every route. Spline's ~1.2 MB runtime is a real tax on enterprise buyers — use it to author geometry, then export GLB into A.

VERSIONING
Tokens are versioned like code: semver, staged deprecation, codemods for renames. A token is never silently repointed — a rename ships as an alias for one minor version, then warns, then breaks.
THE THREE-MINUTE TEST
Sit an engineer who has never seen this system in front of it. If they cannot find a button, place it and configure it correctly in three minutes, the entry point is too complex — simplify before adding anything.
ADDING A PLATFORM
Open a PR against tokens/brands/ with three values and a geometry name. CI resolves all eight theme × mode permutations, runs the contrast gate, and publishes a preview. No design review required for a compliant emitter.
OPEN DECISIONS
Corporate emitter is currently pure white, which gives TAURUS AI no ownable colour of its own. Sentinel and DefQuan from the v1 kit are not represented here. The v1 laser red is retained as the error hue only.
