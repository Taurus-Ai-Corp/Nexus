Security

What freelancers can and can't reach

The workspace is designed to give external creatives power while protecting Taurus AI Corp proprietary systems.

✅

Freelancers CAN access

Design playground with presets, AI image/video generation through APIs, curated RAG design knowledge, their own project files, and export-to-code for their playground configurations.

🚫

Freelancers CANNOT access

Agent prompts, backend architecture, API routes, pricing models, client data, admin approval workflows, raw Pinecone index data, other freelancers' projects, or server-side API keys.

Workflow

Admin approval flow in 60 seconds

Request access

Freelancer submits name, email, portfolio, and specialization via public landing form.

Clerk + admin gate

User is created with `approved=false`. Admin@taurusai.io gets an approval link.

Enter workspace

Middleware checks the approved flag on every protected route. Denied users see a clear contact path.

Ship to production

Freelancer builds in the playground and exports production code to the assigned project path.

FAQ

Frequently asked questions.

Direct answers about capabilities, workflow integration, and pricing.

What is Neormence Studio?
Neormence Studio (Engine 07) is a collaborative workspace designed for marketing agencies, creative studios, and freelance strategists to manage client campaigns under their own white-label domain.
How does Neormence handle client data isolation?
Neormence provides isolated multi-tenant client portals with role-based access control, ensuring brand assets, API credentials, campaign performance data, and billing remain strictly segregated between accounts.
Can agencies white-label reports and dashboards?
Yes, agencies can customize the platform domain, favicon, logo, and email notifications to deliver an end-to-end proprietary branded client experience.
How much does Neormence Studio cost?
Neormence Studio pricing starts at $399 per month and includes 5 client portals, white-label reporting, and team collaboration seats.
