# UAE PQC Assessment Tool - Test Data

This directory contains sample data for testing the UAE PQC Compliance Assessment MVP.

## Files

### sample_inventory.json
A sample cryptographic asset inventory for a mid-sized financial entity in the UAE.
Includes a mix of classical algorithms (many vulnerable to quantum attacks) and a few post-quantum candidates.

## Usage
1. Place this file in the input directory of the assessment tool (or point the tool to this file)
2. The tool will analyze the inventory and generate a gap analysis report
3. Expected output: Identification of RSA, ECDSA, DH, and DSA as vulnerable; AES-256 and SHA-256 as quantum-safe (with note on Grover's algorithm); Kyber and Dilithium as post-quantum candidates

## Sample Data Structure
Each asset has:
- id: Unique identifier
- algorithm: Cryptographic algorithm name
- key_length: Key size in bits
- usage: Where/how the algorithm is used (e.g., TLS, signatures, encryption)
- is_vulnerable: Boolean indicating vulnerability to quantum attacks (based on known attacks)
- notes: Additional context
