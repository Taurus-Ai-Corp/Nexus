- **Colors**: 8-10 core colors with semantic naming
- **Typography**: 6-8 font sizes with responsive scaling

### Animations
- Scroll-triggered fade-ins (300-500ms)
- Micro-interactions (150-200ms)
- Loading states for AI responses
- Smooth transitions (400ms)

### Typography Strategy
- **Primary Font**: Inter (modern, readable)
- **Headings**: 32-48px desktop, 24-32px mobile
- **Body**: 16-18px with 1.5-1.6 line height

### Color Philosophy
- **80/20 Rule**: 80% neutral, 20% brand colors
- **Semantic Colors**: Success, warning, error states
- **Dark Mode**: Optional but modern
