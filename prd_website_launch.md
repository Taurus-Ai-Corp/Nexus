# Product Requirements Document (PRD): Taurus AI Corp Website & Landing Page

## 1. Executive Summary
Taurus AI Corp requires a high-performance, developer-first multipage corporate website and CI/CD/DevOps landing page. This site will serve as the primary marketing and technical entry point for our Tier 1 flagship platforms: **NEXUS by Taurus Ai**, **Gridera by Taurus Ai**, and the unified **NEOFLOW™** platform.

## 2. Target Audience
- DevOps Engineers, Platform Engineers, and DevSecOps practitioners.
- CTOs and technical decision-makers evaluating autonomous AI-agent architectures and post-quantum cryptographic (PQC) readiness.

## 3. UI/UX Structure & Design System
- **Theme:** Default Dark Mode, developer-first, minimalist.
- **Inspiration:** Vercel (Geist), HashiCorp (Helios).
- **Core Principles:** High contrast, legible typography (Monospace for code, Sans-serif for copy), zero layout shift, ultra-fast LCP (Largest Contentful Paint).

## 4. Key Page Sections
### Hero Section
- **Headline:** Clear, concise value proposition (e.g., "Agentic Automation for the Quantum Era").
- **Sub-headline:** Emphasize the powerhouse combination of NEOFLOW™, NEXUS, and Gridera.
- **Call to Action (CTA):** Low friction ("Deploy to Hedera" or "Initialize Workspace").

### Feature Blocks (Show, Don't Tell)
- Code snippets demonstrating **Gridera Quantum** compliance audit logs and ML-DSA implementations.
- Visuals of the **Nexus_Social** dashboard routing capabilities.
- Embedded terminal/sandboxes for CLI commands representing the `taurus-cli`.

### Social Proof & Ecosystem
- Showcase integrations with GitHub, Vercel, Hedera Hashgraph, Playwright.
- Metrics highlighting PQC Readiness assessments and the scale of the 40+ project portfolio spanning the **TAURUS_AI_SAAS** monorepo.

### Workflow Maps
- Diagrammatic flows moving from "commit" to "deployment" utilizing the 24-Agent Hierarchical System, HandoffManager, and NEOFLOW™ architecture.

### Open Source Integrations (Documentation-first approach)
- Highlight Taurus AI Corp's contribution to `hiero-cli` (HIP-1399) and Linux Foundation.
- Direct links to GitHub repositories for `webclaw`, `firecrawl`, and `browser-use`.

## 5. Technical Requirements
- **Framework:** Next.js 16, React 19, Vite, Tailwind 4.
- **Styling:** Vanilla CSS / Tailwind 4 for utility classes.
- **Performance:** Strict adherence to Core Web Vitals (CWV).

## 6. Handoff Note
This document acts as the direct input handoff for Gemini 3.1 Pro and Ollama Launch Claude (Kimi 2.6) for the final rendering of the web views.
