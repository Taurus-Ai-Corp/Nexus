WHAT CHANGED FROM v2 → v3 (5 specific fixes)

  • 5-component formula: Every prompt now has explicit Subject / Action / Location / Composition / Style fields. No more "vibes" prompts.
  • "no text" + copy zone: Every prompt now appends "no text, no labels, no readable words" AND "reserve bottom 22% for headline." This is why the v2 "ambient accent line" was generating random glyphs — Imagen was trying to be helpful.
  • 8-10 element density: Every prompt now lists 8-10 specific elements (background, subject, props, accents, ambient details). The v2 frames had 3-4 elements and looked empty.
  • Brand DNA + banned motifs: Warm amber + dark navy + cyan accent palette. Banned: aurora, glass card, sparkle, neon glow, gradient text. Mandatory: documentary feel, natural light, shallow depth of field.
  • Per-element motion verbs in copy: Headlines now use action verbs (SLAMS, REVEALS, POINTS) instead of passive "we are" / "we wish" phrasing.
