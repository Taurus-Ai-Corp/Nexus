## 🚀 **QUICK START**

### **1. Launch Marketing Studio**
```bash
cd subdomains/neovibe.taurusai.io
python3 Web-Platforms/webflow-integration/webflow_design_mcp.py
```

### **2. Access the Studio**
- **Main Interface**: http://localhost:8000
- **Webflow Integration**: http://localhost:8000/webflow
- **Design Tools**: http://localhost:8000/design

### **3. Create Marketing Assets**
```python
# Example: Landing page creation
result = await webflow_design.create_landing_page({
    "name": "AI Marketing Platform",
    "headline": "Transform Your Business with AI",
    "target_audience": "B2B companies",
    "market": "UAE"
})

# Example: Design system generation
result = await design_ai.generate_design_system({
    "brand_personality": "modern",
    "primary_color": "#3B82F6",
    "target_market": "UAE"
})
```
