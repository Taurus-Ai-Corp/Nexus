## AI Agent Definitions

### 1. Cultural Intelligence Agent
**Purpose:** Market research & cultural analysis for Dubai/India markets  
**MCP Integration:** Website downloader, data analysis tools  
**Output:** Cultural insights, market opportunities, competitor analysis

### 2. Content Creation Agent
**Purpose:** Automated content generation for campaigns  
**MCP Integration:** Figma, design tokens, component library  
**Output:** Visual assets, copy, multimedia content

### 3. Campaign Optimization Agent
**Purpose:** Real-time campaign performance optimization  
**MCP Integration:** Analytics tools, A/B testing frameworks  
**Output:** Optimization recommendations, performance reports

### 4. Lead Generation Agent
**Purpose:** Lead scoring, nurturing, and conversion  
**MCP Integration:** CRM systems, email automation  
**Output:** Qualified leads, conversion metrics

### 5. Client Communication Agent
**Purpose:** Client relationship management & reporting  
**MCP Integration:** Communication tools, reporting systems  
**Output:** Client updates, performance reports, recommendations
