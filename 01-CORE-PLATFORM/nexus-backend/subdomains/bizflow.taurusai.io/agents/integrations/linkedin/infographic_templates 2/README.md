# Infographic Templates

This directory contains templates and assets for generating LinkedIn job posting infographics.

## Usage

Infographics are automatically generated by the `InfographicGenerator` class when creating job postings. They include:

- Company/platform branding
- Job title and key details
- Required skills visualization
- Benefits and perks
- Application information

## Output Formats

- PNG (default) - Recommended for LinkedIn
- JPG - Alternative format
- TXT - Fallback text template when image generation unavailable

## Dimensions

Default infographic dimensions: 1200x1600 pixels (optimized for LinkedIn)

## Brand Colors

- Primary: #1E3A8A (Deep blue)
- Secondary: #3B82F6 (Bright blue)
- Accent: #10B981 (Green)
- Text: #1F2937 (Dark gray)
- Background: #FFFFFF (White)
